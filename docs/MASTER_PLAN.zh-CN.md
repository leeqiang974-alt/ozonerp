# Ozon FBS ERP 总开发计划

本计划受项目根目录 `AGENTS.md` 的最高开发指示约束。阶段目标不可因单个功能请求跳过。

| 阶段 | 目标 | 当前状态 | 验收标准 |
|---|---|---|---|
| 0. 基础约束 | 中文、CNY、店铺隔离、凭据加密、测试基础 | 已完成 | 非 CNY 被拒绝；密钥不回显；项目测试通过 |
| 1. 店铺接入 | 店铺、Ozon 授权、FBS 仓库与删除/停用规则 | 进行中 | 可安全新增、查看授权状态、删除无业务数据店铺 |
| 2. 只读同步 | 商品、SKU、FBS 订单、同步日志与失败重试 | 进行中 | 测试店铺可同步；订单头和商品行可查看；失败可解释和重试 |
| 3. FBS 工作台 | 待打包、截单风险、拣配、面单、交接、异常 | 进行中 | 订单状态与本地库存预占一致；批量处理可审计 |
| 4. 商品库存 | SKU 映射、多仓可售、预占、库存预警与对账 | 未开始 | 库存差异可定位；同步不覆盖人工受控调整 |
| 5. 定价营销 | CNY 定价、最低价、利润保护、活动审批 | 未开始 | 活动价不越过最低价/利润红线；覆盖审计 |
| 6. 报表与运营 | 店铺经营、履约时效、库存风险、营销利润 | 未开始 | 所有指标可回溯到店铺和原始数据 |
| 7. 受控写回 | 库存、价格、营销、发货等 Ozon 写 API | 未开始 | 预检、审批、审计、限流、补偿和灰度验证齐全 |

## 当前阶段：1–3（FBS 工作台基础）

下一项交付按顺序为：

1. 完成店铺仓库管理和店铺授权状态展示。
2. 继续完善 FBS 工作台：订单筛选和截单风险队列已完成；下一项为拣配清单、打包与交接操作的本地状态机。
3. 为受控写回前置增加同步锁、幂等校验和失败重试。
4. 完成仓库只读适配后，再开始库存预占与面单链路。

在上述闭环验收前，不开始 Ozon 写回、广告投放、采购或复杂财务功能。

## 商品上架（本地草稿与预检进行中，Ozon 写回仍待阶段 7）

商品上架采用“草稿—校验—核价—审批—小批发布—任务追踪”路径。详细设计、API 对应与验收标准见 `docs/PRODUCT_LISTING_PLAN.zh-CN.md`；在 FBS 当前工作台阶段仅可开发不含 Ozon 写回的草稿和预检能力。

当前已完成本地单变体草稿、CNY 核价预检、Ozon 末级类目/商品类型缓存、中文类目选择器和必填属性发现。下一步按主线补齐属性字典值、必填属性录入与本地校验；完成前不得进入审批，更不得调用商品导入写接口。
