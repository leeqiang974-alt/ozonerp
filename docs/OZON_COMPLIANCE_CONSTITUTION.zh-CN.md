# Ozon 发布合规最高指示

来源：运营提供的 Ozon 官方“常见错误、商品卡、特征、图片、视频、富内容、条形码与验证”规则截图（2026-09-02）。本文件优先于任何 AI 提示词、批量默认值和“为了通过而自动猜改”的策略。

## 总原则

1. 商品卡是一个完整证据包：标题、描述、属性、SKU、图片、视频、富内容、价格、条码、尺寸重量必须相互一致，并与实际售卖品一致。
2. 平台禁止、侵权、联系方式、站外引流、虚假/仿制、未授权品牌、成人/烟酒、个人隐私和政治内容是安全问题，不得由 AI 猜测性修复；进入人工审核或已创建卡的归档流程。
3. Ozon 的导入回执、审核状态、`price_sent`、仓库库存与条码状态才是最终事实。本地“已处理”不能代替回读。
4. 规则结果分为：`hard_block`（不外发）、`auto_fix_then_recheck`（只处理确定性文字）、`manual_review`（需要素材/授权/类目证据）、`post_submit_monitor`（必须回读）。

## A. 商品卡与属性

| 规则 | 执行方式 |
|---|---|
| 必填属性、类目、类型、保质期、尺寸和重量不得为空；字典属性必须是 Ozon `value_id` | `hard_block` |
| 类目与类型必须是全局 Ozon 缓存中的有效组合；创建后不可随意改关键类型/方面属性 | `hard_block`；已有卡冲突时停止并提示从 Ozon 回拉 |
| 属性文字必须可读，使用俄语/英语及允许字符；尺寸、重量、长宽高仅允许数值 | `hard_block` |
| 类目尺寸/重量限制、仓库是否激活、价格区间 | `hard_block`，并以仓库及 Ozon API 回读复核 |
| 同店/跨店强货源重复、同卡不同颜色/款式被描述为“随机”“不可选择” | `hard_block`；需要拆卡或明确变体 |
| 未授权品牌、侵权图片/他人内容、禁售品 | `manual_review`；已创建按 Ozon 状态归档/删除 |

## B. 标题、描述、主题标签、富内容

所有这些文字面使用同一个内容门禁；富内容只检查可见文本，不把合法图片 URL 当成站外链接。

- 必须是可理解、与商品一致的俄文内容；标题最多 200 字符，单词最多 27 字符，不能是纯拉丁转写、关键词堆砌、重复、乱码、中文、表情或象形文字。
- 禁止联系方式、电话、网址、邮箱、社交账号、二维码、Instagram/Facebook/Telegram 等；禁止引导到 Ozon 之外或其他平台比较/购买。
- 禁止广告和竞争信息：促销、折扣、返现、抽奖、竞赛、优惠码、外部品牌/商城比较、配送时效、物流方式、退货条件。
- 禁止仿制/假货/真实性误导词：`реплика`、`копия`、`подделка`、`1:1`、`AAA`、`original/оригинал` 等，以及“随机款式/随机颜色/无法选择”。
- 成人、烟酒烟草、粗俗语、政治、个人信息等必须按 18+ 与禁售规则处理；儿童商品出现烟酒/成人内容为不可自动修复风险。
- 主题标签是属性，必须按 Ozon 单值/字典规则提交；不得将营销词、品牌词、无关词写入标签。

## C. 图片与视频

- 每个 SKU 的首图必须是对应款式/颜色/尺寸的实际商品；公共图库不得混入其它 SKU、运输包装、无关商品、占位图或误导性拼图。
- 图片必须可从公开 HTTPS 直接下载，尺寸符合 Ozon 限制；提交前实际下载、解码、验尺寸，失败图从外发 payload 排除。每 SKU 无合规图则阻断。
- OCR/视觉审查排除：联系方式、网址、社媒、广告促销、物流/退货、价格、二维码、水印、Instagram/Facebook、政治、个人信息、成人/烟酒、暴力、裸露、仿制/品牌侵权和平台禁售内容。
- 不允许图片/视频模糊、倒置、黑底不符合类目、覆盖超大水印、隐藏违规元素、与标题/属性不符。OCR 或视觉服务不可用时不能视作合规，应进入人工复核。
- 视频还须校验：可播放、长度不超过 5 分钟、符合类目画幅（服装竖屏 3:4，其他默认方形 1:1），无水印、站外引流、广告、隐私、政治、烟酒或成人内容。
- AI 生成图仅能基于已验证的单一 SKU 参考图，禁止添加未证实卖点、品牌、认证、价格、文字、旗帜/政治或身份宣传；生成结果仍须通过同一媒体门禁。

## D. 条码、价格、仓库和回执

- 条码必须是唯一且可用的 Ozon 条码；被占用、失效或 SKU 回应超时必须保存原始错误，修复商品卡后重新生成/回读，禁止伪造成功。
- 价格必须满足所选类目允许区间；自动定价使用后端唯一公式与价格下限。若平台要求整数而当前接口/币种规则不一致，进入人工复核，不能静默截断。
- 仓库必须激活且接受货物；库存只在全部 SKU 的导入回执可接受、商品为 `price_sent` 后写入，并以 FBS 仓库库存回读确认。
- 所有提交保留任务 ID、逐 SKU 原始错误/警告、修复次数和审计。`WARNING` 留档但不等同失败；明确 `ERROR` 按规则处理，自动重试有上限。

## 工程落点与验收

| 环节 | 必须执行 |
|---|---|
| 采集/素材入库 | 原始证据不改写；OCR/视觉风险留档；风险源全局封禁 |
| 草稿保存 | 类目属性字典、SKU 图片隔离、标题/描述/富内容结构校验 |
| 手工和批量提交 | 同一 `quality_preflight`，先自动确定性清理，再复检；任何 `hard_block` 均不得调用 Ozon 写 API |
| Ozon 回执 | 轮询导入、审核、条码、`price_sent`、库存；按错误分类自动修复或人工审核 |
| 已创建违规商品 | 依据 Ozon 可读状态：存在则归档并回读；运营已处理则记录其事实，不重复写入 |

验收最低标准：规则单元测试、前后端语法、笔记本 `/health`、一条手工提交阻断验证、一次真实 Ozon 回执/库存只读回查。任何未验证项必须明确标记未完成。
