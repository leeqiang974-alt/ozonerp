# 中文 FBS ERP 操作界面

## 设计原则

- 日常操作不超过三步：选择店铺 → 筛选任务 → 批量处理/确认。
- 顶部全局店铺筛选始终可见；默认展示“全部店铺”，数据表仍保留店铺列。
- 红色只表示会造成履约或利润损失的风险；蓝色用于可操作按钮；成功状态使用绿色。
- 所有金额标示 `CNY`；所有日期使用中国时区展示。

## 页面与操作

| 页面 | 默认内容 | 核心动作 |
|---|---|---|
| 工作台 | 待打包、截单风险、缺货、待审批活动、同步失败 | 进入对应筛选列表、立即同步 |
| 店铺管理 | 店铺卡片、授权状态、同步时间、仓库 | 新增/停用店铺、配置仓库、查看同步日志 |
| FBS 订单 | 状态 Tab、截单倒计时、商品明细 | 批量进入打包、打印面单、确认交接、异常标记 |
| 商品与库存 | SKU、可售/预占、库存风险、最近同步 | 批量导入、调整库存、查看变动记录 |
| 定价与营销 | CNY 成本/售价/最低价/利润、活动状态 | 试算、提交活动审批、批准或驳回 |
| 同步中心 | 每次运行状态、游标、数量、失败原因 | 单店/全店只读同步、失败重试 |

## 交互组件

- 左侧固定导航：工作台、店铺、商品库存、FBS 订单、定价营销、同步中心、系统设置。
- 列表页：快捷状态 Tab、筛选器、保存筛选、复选框批量操作、右侧详情抽屉。
- 高风险操作：显示影响店铺、SKU/订单数量与 CNY 金额；确认后写入审计日志。
- 空状态：提供明确的下一步按钮，例如“添加店铺”或“同步商品”，而不是空白表格。
